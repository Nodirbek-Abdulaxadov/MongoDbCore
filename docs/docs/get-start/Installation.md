# Installation

To install MongoDbCore, add it to your project using NuGet sources:

### .NET CLI:
```cmd
dotnet add package MongoDbCore --version 2.0.0
```

### Package Manager:
```cmd
NuGet\Install-Package MongoDbCore -Version 2.0.0
```

### Package Reference:
```csproj
<PackageReference Include="MongoDbCore" Version="2.0.0" />
```

> **Target frameworks:** `net8.0` and `net9.0`.
